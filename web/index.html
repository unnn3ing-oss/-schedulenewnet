安裝 Chrome 插件

網新快速排程要透過這個插件帶著網新後台的登入送出。只要做一次，約 2 分鐘。

步驟 1／5

下載安裝檔

網頁沒辦法直接替瀏覽器安裝插件。這個安裝檔會從 GitHub 帶著最新版插件，放到你電腦的固定資料夾，再幫你打開 Chrome 的擴充功能頁。

  1. 按「下載安裝檔」，會下載 schedulenewnet-install.cmd。
  2. Chrome 若顯示「這類檔案可能有害」，請在下載清單按「保留」。
  3. 出現「已下載安裝檔」後，按「下一步」。
公司電腦不能執行安裝檔？改用手動安裝

先在電腦上建一個空資料夾（例如「文件」裡新增 schedulenewnet-ext），按「選擇資料夾並寫入」選它，Chrome 問要不要讓網站編輯檔案時按「編輯檔案」。不能選資料夾的瀏覽器就按「下載 ZIP」，下載後先解壓縮。完成後跳到步驟 3。

步驟 2／5

執行安裝檔

安裝檔會把插件放到「文件」裡的 schedulenewnet-ext 資料夾、把路徑複製好，並打開 Chrome 的擴充功能頁。

  1. 點 Chrome 下載清單裡的 schedulenewnet-install.cmd（或到「下載」資料夾連點兩下）。
  2. 出現藍色的「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。
  3. 出現「網新快速排程 安裝程式」視窗，按「開始安裝」。
  4. 顯示「檔案已經放好了！」後，視窗裡有步驟 3、4 的圖解，可以開著對照；做完按「完成」關掉。
  1. 按下面的「複製指令」。
  2. 按 ⌘ + 空白鍵 搜尋「終端機」並打開，按 ⌘ + V 貼上，再按 Enter。
  3. 跳出「網新快速排程 安裝程式」對話框時，按「開始安裝」。
  4. 顯示「檔案已經放好了！」後，照對話框的兩步做（就是下面步驟 3、4），按「完成」後就可以關掉終端機。
bash ~/Downloads/schedulenewnet-install-mac.sh

沒有自動打開擴充功能頁？　複製下面的網址，貼到 Chrome 網址列再按 Enter。

chrome://extensions
終端機顯示「No such file or directory」？

代表安裝檔不在「下載項目」資料夾，或 Chrome 幫它改了名字（例如多了「 (1)」）。請在終端機輸入 bash 和一個空格，再把安裝檔從 Finder 拖進終端機視窗，按 Enter。

步驟 3／5

打開「開發人員模式」

這個插件不是從 Chrome 線上應用程式商店安裝的，所以要先打開「開發人員模式」，Chrome 才允許載入自己的資料夾。

  1. 到安裝檔打開的擴充功能頁，在右上角找到「開發人員模式」開關。
  2. 點一下開關，變成藍色就是打開了。
  3. 打開後，左上方會多出「載入未封裝項目」「封裝擴充功能」「更新」三個按鈕，下一步會用到第一個。

小提醒　偶爾重開 Chrome 時，會跳出關於「開發人員模式擴充功能」的提醒，直接關掉就好，不要按「停用」。

步驟 4／5

載入插件

接下來告訴 Chrome：插件檔案放在哪個資料夾。安裝檔已經把路徑複製好了，直接貼上就好。

要選的資料夾

schedulenewnet-ext
  1. 按擴充功能頁左上角的「載入未封裝項目」。
  2. 在跳出的視窗下方「資料夾」欄位按 Ctrl + V 貼上路徑，再按「選擇資料夾」。
  3. 在跳出的視窗按 ⌘ + ⇧ + G，按 ⌘ + V 貼上路徑後按 Enter，再按「選取」。
  4. 清單裡出現「網新快速排程 連線驗證」，就載入成功了。

以前用安裝檔裝過？　不用再載入一次，在擴充功能頁找到這個插件，按卡片上的重新整理圖示即可。

出現「無法載入擴充功能」或「找不到 manifest」？

代表選到上一層了。請再往裡面點一層，直到打開資料夾就能直接看到 manifest.json、bridge.js 等檔案，再選那一層。用 ZIP 解壓縮的話，最常多包一層。

步驟 5／5

重新整理，開始使用

裝好了！回到這個網頁重新整理，右上角顯示「外掛已連線」就能開始排程。

  1. 按「完成」關掉教學，再按 F5（Mac 按 ⌘ + R）重新整理這個網頁。
  2. 右上角顯示「外掛已連線」就成功了；如果顯示「尚未登入網新」，先到網新後台登入一次再回來。
  3. （建議）點網址列右邊的拼圖圖示，在「網新快速排程 連線驗證」右邊按圖釘，釘選到工具列。
  4. 點工具列上的圖示會打開側邊欄，之後更新外掛都在這裡。

之後要更新　不用回到這裡。側邊欄按「檢查更新」→「更新到最新版」；外掛也會定時檢查，有新版會在圖示上顯示「新」。
